# Starfield Console Commands

A searchable list of every console and script command in Starfield, read from the game's own command table in `Starfield.exe` (game version 1.16.244.0).

**View it here:** https://taosecurity.github.io/starfield-console-commands/

- 1,383 commands in 15 topics, with a "Most commonly used" group first.
- Each command shows its short form, parameters and the game's own help text, plus an example built from real game IDs.
- Search, filter by console or script commands, and click a name to copy it.

Made by Richard Bejtlich of [Richard Presents Starfield Essentials](https://www.youtube.com/@RichardBejtlich).

## Notes

- This is an unofficial list, not made or endorsed by Bethesda. Starfield is a trademark of ZeniMax Media. The command names and help text are the game's own.
- Commands that SFSE plugins add are not included.
- The examples were not run in the game. They show a valid shape with real values.
- The list is regenerated after game updates.

The page is a single self-contained `index.html` with no external dependencies. Its code (layout, search and copy features) is MIT licensed; see `LICENSE`.
