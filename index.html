Console commands (438)

Built for the debug console only: toggles like tgm and tcl, teleports like coc, dumps, saving and loading. They change or report on the game as a whole. Most have a short form.

What they cover: cheats and toggles (tgm god mode, tcl no collision, tm hide the menus for screenshots), travel (coc, cow, movetoqt), picking things (prid selects a reference by its ID), quests and Papyrus (sqv, cqf, the DumpPapyrus… reports), settings (setgs, setini) and many developer tools for rendering, memory and pathing that do little in a normal game.

Script commands (945) script

Functions from the engine's older built-in script language, such as additem, setstage and getav. They work in the console too, often on a target (player.additem), and many Get/Is ones exist mainly as conditions in the Creation Kit; in the console they just print a value. These are not Papyrus, the language mods are written in today. Some names exist in both (e.g. SetStage), but the console runs the old version; to reach a mod's Papyrus script from the console, use cf or cqf. More below.

The labels

target The command works on one object or person, not the whole game. Click it with the console open (its ID shows at the top of the console), then type the command; or put an ID in front, e.g. player.additem or 00005986.moveto player. With nothing selected, many target commands do nothing or act on the player.

script A script command (see the Script commands box). No label means a console command.

e.g. lines under a name show the command typed out with real values. See Example IDs for what each ID is.

How to use

  • Open the console with ~. Type the full name or the short form; upper and lower case work the same.
  • Target commands work on the selected reference. Click an object or person while the console is open, or put a prefix in front, e.g. player.additem.
  • In the Parameters column, <Name> is required and [Name] is optional. Items, NPCs and quests are given by FormID or editor ID. For quests and globals from light plugins (ESL-flagged) the console often can't find the editor ID, so use the FormID.
  • Every command has an example. The values are real IDs from Starfield.esm (listed under Example IDs), but the examples were not run in the game: they show a valid shape, and a command can still refuse a value that makes no sense for it. File names such as TestSave01 or MyMod.esm stand for your own.
  • help <word> searches the same list inside the game.
  • Topics are sorted by command name patterns, so a few commands may sit in a surprising group. Search finds them anywhere.

What's in this list

Console commands, script commands and Papyrus

Starfield has two separate scripting systems, and both have "script" in the name.

The old script language (modders call it ObScript) dates back to Morrowind and Oblivion, when mods were written in it. In Starfield it survives in two places only: the console, where player.additem 0000000F 100 runs one of its commands, and conditions in the Creation Kit, e.g. "only show this dialogue line if GetStage MQ101 >= 10". Most of the Get/Is script commands exist for those conditions, which is why typing them in the console just prints a number. Nobody writes script files in it anymore.

Papyrus is the language used since Skyrim, and the one mods use: .psc source files compiled into .pex and attached to quests, objects and magic effects. You can't type Papyrus into the console. The console reaches it only indirectly:

  • cf (CallFunction) calls a function on the selected object's script; cqf calls one on a quest's script; cgf calls a global function.
  • sv and sqv show a script's variables.
  • The DumpPapyrus… commands report on running Papyrus scripts to the Papyrus log.

Same names, different things. SetValue, AddItem and SetStage are console script commands, and Papyrus has functions with the same names (Actor.SetValue, ObjectReference.AddItem, Quest.SetStage). They do similar jobs but aren't the same thing. This page lists what you can type in the console; it doesn't list the functions a Papyrus mod can call. For those, use a Papyrus reference such as the Creation Kit wiki.
